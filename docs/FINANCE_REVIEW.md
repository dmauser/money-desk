# Finance review sheet

> Generated by `scripts/generate-review-sheet.mjs` (runs in `npm pretest`). Do not edit by hand — change the skill, then regenerate.

Every skill decides with explicit numeric rules so that the same inputs always give the same recommendation. Those rules, and the defaults used when a user has no view, are **judgment calls made while standardising the skills — they have not been reviewed by a licensed professional.** This sheet lists all of them so a reviewer can confirm or correct each one.

## How to review

1. For each skill below, read the **Decision rules** (what the skill recommends and when) and the **Assumed defaults** (values it uses when the user gives none).
2. Mark the skill in the sign-off table: ✅ agree, ✏️ change (say what), ❓ needs discussion.
3. To change a rule, edit that skill's `SKILL.md`. If the skill is listed with a calculator, change the same rule in `extensions/money-desk/calculators.mjs` in the same commit — the calculator implements the table.

Statutory figures (tax brackets, limits, IRS tables) are **not** on this sheet; they live in `extensions/money-desk/data/facts-2026.json` with their primary sources.

## Budget Coach

### Cashflow Review

`budget-coach/skills/cashflow-review/SKILL.md`

**Decision rules**

Evaluate top to bottom; the first match is the **primary next step**. Secondary steps: add "Subscription Audit" whenever `recurring_small_usd_per_month` ≥ $50, and "Category Audit" whenever any month has an Overspend flag (if not already primary).

| # | Condition | Primary next step |
|---|---|---|
| 1 | Joint accounts and `household_scope` not given | Stop before savings rate — ask whose income/spending it is |
| 2 | `window_savings_rate_pct` < 0 | Deficit — run Category Audit, then Monthly Plan; if debt minimums are part of the gap, route to Debt Strategist |
| 3 | 0 ≤ `window_savings_rate_pct` < 10 | Thin margin — Category Audit, then Monthly Plan targeting ≥ 10% |
| 4 | 10 ≤ `window_savings_rate_pct` < 20 | Moderate — Monthly Plan to lock in the rate; Category Audit to find room toward 20% |
| 5 | Otherwise (≥ 20%) | On track — Monthly Plan to formalize; route surplus to Net Worth & Goals |

**Assumed defaults**

| Assumption | If the user doesn't supply it | Tag |
|---|---|---|
| Cash-only activity not on statements | Treated as $0 and stated in the report | `[ASSUMPTION]` |

### Monthly Plan

`budget-coach/skills/monthly-plan/SKILL.md`

**Decision rules**

Evaluate top to bottom; the first match wins. `D` = Σ variable allocations in `discretionary_categories`; `S` = savings total.

| # | Condition | Plan action |
|---|---|---|
| 1 | fixed total ≥ baseline income | Not plannable — fixed costs consume all income; route to Debt Strategist if debt minimums ≥ 20% of baseline, else flag housing/income review |
| 2 | shortfall ≤ 0 | Balanced — assign surplus per step 9 |
| 3 | shortfall ≤ 0.5 × D | Cut discretionary categories pro-rata by the shortfall; mark each cut "stretch" |
| 4 | shortfall ≤ 0.5 × D + 0.5 × S | Cut discretionary by 0.5 × D, then savings goals pro-rata for the rest; flag "savings below goal" |
| 5 | Otherwise | Deficit plan — show the unbalanced plan and the gap; route to Category Audit for cuts and Debt Strategist if debt minimums are present |

Re-run triggers: any fixed obligation changes by > 10%, or quarterly.

**Assumed defaults**

| Assumption | If the user doesn't supply it | Tag |
|---|---|---|
| Plan style | `zero_based` | `[ASSUMPTION]` |
| Discretionary buffer | 5% of baseline income; 10% when `income_irregular` = true | `[ASSUMPTION]` |

### Tax-Loss Harvest Review

`tax-planner/skills/tax-loss-harvest-review/SKILL.md`

**Decision rules**

Per lot; evaluate top to bottom; the first match wins.

| # | Condition | Recommendation |
|---|---|---|
| 1 | Not in a taxable account | Not harvestable |
| 2 | Wash-sale conflict from a past purchase (within 30 days before the sale) | Blocked — wait until 31 days after that purchase |
| 3 | Wash-sale conflict from a scheduled buy / DRIP after the sale | Harvest only after cancelling the scheduled buy / turning off DRIP; otherwise blocked |
| 4 | `|loss| < min_loss_usd` (default $200) | Skip — below floor |
| 5 | Long-term lot and the user's LTCG rate + NIIT + state rate = 0 and no ordinary offset capacity remains | Skip — no current-year tax value |
| 6 | Otherwise | Harvest; buy the step-7 replacement; earliest re-buy date = sale + 31 days |

**Assumed defaults**

| Assumption | If the user doesn't supply it | Tag |
|---|---|---|
| Harvest floor per lot | $200 (this skill's convention) | `[ASSUMPTION]` |
| Crypto wash-sale treatment | Apply the 30-day test anyway (conservative) and label it | `[ASSUMPTION]` |
| Substantially identical | Same ticker, or a fund tracking the **same index** from a different issuer = substantially identical (conservative) | `[ASSUMPTION]` |

### Cash Yield Check

`investing-advisor/skills/cash-yield-check/SKILL.md`

**Decision rules**

The skill presents a ranked shortlist; it never picks an institution. Evaluate top to bottom; first match wins.

| # | Condition | Output |
|---|---|---|
| 1 | No live rate source reachable | Stop — tell the user; no figures |
| 2 | Fewer than 1 product passes the filter | Relax constraints list: show which filter removed the most products; ask the user which to relax |
| 3 | After-tax $ pickup of the #1 ranked option < $100/yr | "Current account is within $100/yr of the best eligible option — switching is optional" |
| 4 | `amount_usd` > insured limit and #1 is a deposit product | Shortlist + "split across institutions or use a network-sweep program" |
